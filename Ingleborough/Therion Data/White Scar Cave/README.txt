11.11.2019

The White Scar Cave data set was started with the intention of combining point cloud of the show cave with normal survey data. 
Some sucsess has been had with this but as is the way with these things this project has snowballed a bit.
 
As well as trying to get a digital 2d map we are now using GIS to create 3d models of the area. 
The BCRA CSG are currently experimenting to see if GIS is to be the future of cave surveying, the White Scar Cave data set is part 
of these trials and as such is work in progress.

A resurvey of the whole cave would be nice but at the moment it is unlikely this will be done due to time constraints, 
however if anyone would like to help or just get on with it then we will gladly assist wherever possible.  

Also it seems we may soon have a reliable solution to digitising a lot of existing paper surveys which will hopfully remove the 
need to resurvey dozens of caves just to recreate the lost data. There will be constraints but so far the work looks promising.

If the whole White Scar Cave data set is downloaded then it will work with Therion, all the outputs are pointed at the correct 
folders and everything should work correctly.

The WhiteScarIndex.th and the associated thconfig above it are the main files to bring the whole data set together. 
The Output folder already contains the 2d pdf and Google Earth kml of the cave so far.
