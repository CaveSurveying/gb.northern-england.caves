The White Scar Cave data set was started with the intention of combining point cloud of the show cave with normal survey data. 
Some sucsess has been had with this but as is the way with these things this project has snowballed a bit. 
As well as trying to get a digital 2d map we are now using GIS to create 3d models of the area. 
The BCRA CSG are currently experimenting to see if GIS is to be the future of cave surveying, the White Scar Cave data set is part 
of these trials and as such is work in progress. 

If the whole data set is downloaded then it will work with Therion, all the outputs are pointed at the correct folders 
and everything should work correctly.
