West Kingsdale Project folder created by Footleg (June 2013)

Contains West Kingsdale Therion drawing project including all raw sketches and 
PocketTopo data files. The centreline data used for the Therion drawings is 
provided via a processed Survex .3d file in the West Kingsdale Therion project 
folder. This .3d file has to be generated using Survex v1.1.13 or earlier in 
order for Therion to be able to read it.
